TMX 校稿編輯器

校對：中英分欄對照，譯文可直接編輯，逐段「確認」或篩選後「全部確認」
篩選：未翻譯 / 未確認 / Claims / Desc / 已編輯 / AI✎ / AI⚠ / 關鍵字搜尋 / 搜尋取代
自動處理：偵測段落區段（Claims / Description / Abstract）、跳過編號行與 CJK 原文行、後處理修正空格（圖1、步驟S1、請求項1）
匯出：檔名自動附加時間戳記（YYMMDDHHMM），可下載或複製
寫回工作目錄：Chrome/Edge 可直接寫回 case_dir 與 OmegaT tm/（File System Access API），iPad Safari 等不支援環境維持匯出＋手動搬檔
相容：OmegaT TMX（自動剝除 DOCTYPE）、tmx_review.py 標記（【✎ / 【⚠）、批次翻譯回音標記（⚠(BATCH_ECHO)）
結構保全：zh 譯文含 OmegaT inline tag（<bpt>/<ept>/<ph> 等）者鎖定唯讀，不可編輯／確認，避免攤平破壞結構
移除：tmx_review.py 標記（【✎ / 【⚠）、⚠(BATCH_ECHO) 回音標記。只有該筆譯文含有對應 tag 時才會出現，不會佔用畫面空間。
