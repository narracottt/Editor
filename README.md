## 📝 markdown-editor.html

Markdown 即時預覽編輯器。

**功能**
- 即時分割預覽 / 純編輯 / 純預覽 / 筆記四種模式
- 手機預設全寬預覽，編輯與預覽可一鍵切換；格式工具列可左右滑動
- 筆記模式依發生日期分組，同一天按時間排列；補記另以小字顯示記錄時間
- 筆記模式可逐筆跳到原文編輯再返回原位置、列出格式有問題的行、切換最新日期在前，並以「待辦記錄」標籤顯示 `+` 待辦
- 可修改匯出檔名，開啟檔案時保留月份檔名
- 顯示瀏覽器草稿與待匯出狀態，重新開啟可還原內容及檔名
- 支援的瀏覽器可直接存回原檔；存檔前核對原檔，保留開啟後新增的 lifelog 記錄
- 支援 Mermaid 流程圖（含 render cache 與語法驗證）
- 全文搜尋與取代
- 匯出 .md / .html
- 深色模式

**使用方式**：
- [開啟 markdown-editor](https://narracottt.github.io/Editor/markdown-editor.html)
- 下載 `markdown-editor.html`，用瀏覽器開啟即可。

**手機使用**：用上述網址開啟編輯器，可透過瀏覽器選單加入主畫面。點「開啟」選取 Markdown 檔，點「編輯」修改，再按「匯出 .md」，重新選取原檔核對後下載副本。

**儲存方式**：草稿只保存在目前瀏覽器，每次載入其他文件會取代草稿；不會同步到其他裝置。開新文件或載入檔案前，若目前內容尚未儲存，會先提醒。首次使用會沿用舊版瀏覽器草稿。Mermaid 與完整 Markdown 解析仍透過既有 CDN 載入。

- **直接存回原檔**（支援 File System Access API 的瀏覽器，例如電腦版 Chrome／Edge）：按「💾 儲存」或 Ctrl+S 寫回開啟的檔案。Brave 需先在 `brave://flags/#file-system-access-api` 開啟。重新開啟頁面後，還原的草稿不帶存回目標，第一次儲存要重新選取原檔，檔名與內容都要對得上。儲存進行中會暫時鎖住編輯。
- **核對後匯出**（其他瀏覽器）：按「⬇ 匯出 .md」會請你重新選取原檔，核對後下載副本，原始檔案仍需自行替換。
- **存檔前核對**：兩種方式都會重讀原檔。原檔若在開啟後多了完整的 `- YYMMDD HH:MM` 記錄，會接在編輯後的內容後面一起存；原檔有其他刪改、截斷，或新增的記錄有任何一筆日期時間無效、結尾不完整，就停止儲存並提醒。新增記錄的續行必須縮排兩格。lifelog 檔不論儲存、另存或匯出副本，都會補上結尾換行。
- **限制**：核對無法涵蓋尚未同步到這台裝置的變更，也無法涵蓋下載副本後手動替換前的變更。用同步資料夾時請保留版本紀錄與衝突副本。
- 「更多 → 匯出副本 .md」維持原本不核對、直接下載的行為。

**Lifelog 閱讀**：開啟以 `- YYMMDD HH:MM 內容` 記錄的檔案，點「筆記」會將相同發生日期的記錄整理在一起，日期由早到晚，同一天按發生時刻排列。內容開頭若有有效的過去日期代碼（在記錄日前 365 天內），視為補記；有事件時刻就顯示，未填時刻的補記排在當天最後，並標示實際記錄時間。多行內容仍屬於原記錄。分組僅用於筆記模式，原有「預覽」保留一般 Markdown 呈現；編輯文字、Markdown／HTML 匯出與 HTML 複製都維持原始內容及檔案順序。分組範圍是目前開啟的文件；沒有日期記錄的文件，在筆記模式會提示並顯示一般內容。

- **辨識**：以 `- YYMMDD HH:MM` 記錄開頭的文件，或檔名為 `YYYY-MM.md` 且含記錄的文件，視為 lifelog。開啟時直接進筆記模式並捲到最新一天；「最新在前」只改日期群組的顯示順序，同一天內的順序、原文與匯出內容都不變。其他 Markdown 文件維持一般預覽，不做格式診斷。
- **逐筆編輯**：每筆旁的 ✎ 會切到原文並選取該筆內容（不含記錄時間戳；補記會包含事件日期代碼）。改完按「↩ 筆記」回到同一筆，即使它因改日期而換了分組。
- **格式診斷**：以下三種原文不列入分組，改在筆記最上方完整列出並標示行號，狀態列與存檔訊息也會提示處數；編輯器不會自動修正，也不會擋下存檔。
  - 日期或時間無效的記錄行（例如 `- 261332 09:30`、`- 261006 25:00`），連同它的續行。
  - 形狀接近但不符的記錄行（例如 `- 26100 9:30`、`-261006 09:30`）；bot 會把這種行併入上一筆。
  - 第一筆記錄之前的文字。

  沒縮排的續行、程式碼區塊內的文字不算問題。存回原檔時的合併檢查不受影響，仍要求新增記錄完整且續行縮排兩格。
- **待辦記錄標籤**：依 bot 建立待辦的位置判斷——記錄內容開頭的 `+`／`＋`（可在今天或未來的日期代碼之後）、待辦記錄後續行開頭的 `+`／`＋`（程式碼區塊內也算，與 bot 相同）、補記內容開頭的 `+`／`＋`。一般記錄的續行、行中間的加號、`\+`／`\＋` 都是一般文字。標籤只表示原文帶有待辦標記，不代表 Notion 待辦已建立或尚未完成；在編輯器增刪或修改 `+` 行，不會建立、取消或更新 Notion 上的待辦。
- **副本狀態**：下載副本後，狀態列顯示「副本已下載，待替換原檔」，直到存回原檔或重新開啟原檔為止；這個狀態不代表同步資料夾已把檔案送到其他裝置。
